How League Scoring Works

Match Points (Per Match)

Every match you play earns base points:

Result Points
Win 3
Draw 1
Loss 0

These are added up across the event before any multipliers or bonuses.

Event Weight (Multipliers)

Some events count more toward the season race.

Event Series Multiplier
BCPMM (Championship) 8×
Stronghold Monthly 3×
Connections 2xMonthly 2×
BC Winter League (BCWL) 1×

Your base match points are multiplied by that event’s weight.

Example: Go 3-1 at Stronghold (9 base points). 9 × 3 = 27 race points.

Bonus Points

Some events award extra bonuses for finishing position.

BCPMM (Top 8)

FinishBonus
1st+200
2nd+100
3rd–4th+50
5th–8th+25

Stronghold Monthly

  • 1st place: +30

Connections

  • 1st place: +20

Final event score = Match Points × Multiplier + Bonus.

Elo Rating

Elo measures performance strength, not attendance.

  • Everyone starts at 1600.
  • Beating higher-rated players earns more points.
  • Losing to lower-rated players costs more points.

Different event tiers adjust rating faster:

SeriesRating Volatility
BCPMMVery High
StrongholdHigh
ConnectionsMedium
BCWLLow
Championship matches move ratings the most. League matches move them the least.

Win Streaks & Flames

Flames track consecutive wins across all events. They do not affect points or rating.

  • 🔥 = 2 wins in a row
  • 🔥🔥 = 3 or more wins in a row
  • Draw or Loss resets the streak

Important Notes

  • All leaderboards are rebuilt directly from match records.
  • No ratings are manually edited.
  • If a result is wrong, the match record is corrected — not the leaderboard.
