Event JSON Template

Use this structure when uploading events via the Admin panel.

Reference example: stronghold-2026-02-01.json

Top-Level Structure

{
  "event": { ... },
  "rounds": [ ... ],
  "standings": [ ... ],
  "elimination": { ... },   // optional
  "notes": [ ... ]          // optional
}
Only event, rounds, and standings are required. ---

event

"event": {
  "id": "stronghold-2026-03-01",
  "name": "Stronghold Monthly",
  "date": "2026-03-01",
  "series": "SHG",
  "location": "Stronghold Games",
  "format": "Premodern"
}
Definitions:
  • id — Optional. A slug-style identifier. Format: seriesname-YYYY-MM-DD (lowercase, hyphenated).
  • name — Required. Public event name.
  • date — Required. Must be YYYY-MM-DD.
  • series — Required. One of:
    • BCPMM
    • SHG
    • CONNECTIONS
    • BCWL
  • location — Optional text.
  • format — Optional text.
---

rounds

"rounds": [
  {
    "round": 1,
    "matches": [
      {
        "table": 1,
        "playerA": "elliot-fisher",
        "playerB": "james-onions",
        "gamesA": 2,
        "gamesB": 1
      }
    ],
    "byes": ["kevin-mittertreiner"]
  }
]
Definitions:
  • round — Required. Round number (integer).
  • matches — Required. Array of match objects.
  • table — Optional. Table number.
  • playerA / playerB — Required. Must match existing player slug exactly.
  • gamesA / gamesB — Optional but recommended. If omitted, win/loss defaults to 2–0.
  • byes — Optional array of player slugs receiving a bye.
Draws are represented by equal game counts (e.g., 1–1). ---

standings

"standings": [
  { "rank": 1, "player": "elliot-fisher" },
  { "rank": 2, "player": "james-onions" }
]
Definitions:
  • rank — Required integer finish position.
  • player — Required slug.
Optional tiebreaker fields (safe to include):
  • match_points
  • omw
  • gw
  • ogw
---

elimination (optional)

"elimination": {
  "quarterfinals": [ ... ],
  "semifinals": [ ... ],
  "finals": [ ... ]
}
Same match format as Swiss rounds. Used primarily for BCPMM bonus logic. ---

notes (optional)

"notes": [
  "Player slugs normalized",
  "No elimination bracket"
]
Free-form text. Not required. ---

Common Errors

  • Incorrect date format
  • Slug mismatch
  • Missing standings array
  • Malformed JSON
---

If unsure, duplicate the Stronghold example file and modify only necessary values.
